Analizador de Espectro y Fourier en Tiempo Real (Audio Web API)

Aplicación web interactiva diseñada para la captura, procesamiento y visualización de señales de audio en tiempo real mediante el uso de la API Web Audio y algoritmos de análisis espectral.

Características Principales:
Entrada de Audio: Se puede usar el micrófono o la salida de alguna página (como spotify)
Visualización de Onda: Osciloscopio interactivo con capacidad de alternar entre representación continua y muestreo discreto
Transformada de Fourier (DFT / FFT): Espectro de magnitud en frecuencia en tiempo real
Detección Automática de Picos: Identificación visual de armónicos dominantes con etiquetas numéricas exactas en Hertz (Hz) en la base del espectro
Espectrograma: Gráfico temporal con colores configurables y ajuste de sensibilidad
Gráfico de Muestreo (Stem Plot): Visualización de las muestras discretas x[n] con codificación de polaridad
Fundamento Matemático: Panel de ecuaciones (Transformada Continua, Discreta y parámetros de muestreo Nyquist)
